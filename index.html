Update your GitHub Pages site

After downloading the updated ZIP:

  1. Unzip the downloaded file.
  2. Open your website repository on GitHub.
  3. Choose Add file → Upload files.
  4. Drag in all updated files and allow replacements.
  5. Select Commit changes. GitHub Pages usually updates shortly afterward.
