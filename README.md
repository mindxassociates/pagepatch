# PagePatch

[Try PagePatch](https://mindxassociates.github.io/pagepatch/) · [Report a problem](https://github.com/mindxassociates/pagepatch/issues)

PagePatch is a bilingual, browser-based visual editor for existing static websites. Open an HTML file or website ZIP, make visual changes, preview common screen sizes, and download the updated site—without installing software or uploading the project to a server.

Chinese is the default interface language; use the compact **中 / EN** control to switch languages.

## Highlights

- Opens `.html`, `.htm`, and complete website `.zip` files
- Preserves supporting files and relative asset paths in ZIP projects
- Edits text, typography, colors, spacing, sizing, links, images, and element HTML
- Adds or replaces images with alt text, optional links, sizing, and alignment
- Includes desktop, tablet, and mobile preview widths
- Supports undo, redo, direct-on-canvas editing, and keyboard shortcuts
- Exports one HTML page or an updated website ZIP
- Performs editing and export locally in the browser
- Includes bilingual help and GitHub Pages upload instructions

## Quick start

Use the hosted editor, or run it locally:

```bash
git clone https://github.com/mindxassociates/pagepatch.git
cd pagepatch
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Basic workflow

1. Open or drag in an HTML file or website ZIP.
2. Select an element in the page preview.
3. Change its content or styles in the Properties panel.
4. Switch to Preview to test the page in an isolated frame.
5. Download the updated HTML or complete ZIP.
6. Upload the replacement files to your GitHub Pages repository.

Keyboard shortcuts:

| Action | Shortcut |
| --- | --- |
| Undo | `Ctrl/Cmd + Z` |
| Redo | `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y` |
| Download | `Ctrl/Cmd + S` |
| Close a dialog | `Esc` |

## Security model

PagePatch treats imported websites as untrusted:

- Edit mode removes imported scripts and inline event handlers before displaying the page.
- Interactive Preview runs in a sandboxed, opaque-origin iframe.
- Preview navigation receives no referrer information.
- Potentially executable `javascript:` and `vbscript:` links are rejected.
- HTML input is limited to 5 MiB and ZIP input to 25 MiB.

This isolation reduces risk but does not make arbitrary HTML safe to trust. Only open files from sources you recognize. PagePatch processes imported project data locally, but external resources referenced by a site and the JSZip CDN dependency may still make network requests.

## Compatibility

PagePatch is designed for static HTML/CSS/JavaScript sites. Visual edits modify the generated HTML, not source templates or component state. React, Vue, Next.js, Astro, and similar build-tool projects should normally be edited in their source code.

Complex sites may have limitations:

- CSS generated by JavaScript is unavailable in Edit mode.
- Dynamic text may reappear from its original script when Preview starts.
- Cross-origin resources can be blocked by their own security policies.
- The ZIP must include an `index.html` or another HTML entry file.

## Development

The application intentionally remains a single deployable HTML file. No build step or production dependencies are required.

```bash
npm test
```

The test suite checks the standalone artifact's structure and core security controls. GitHub Actions runs it on pushes and pull requests.

## Publishing PagePatch

This repository includes `.nojekyll`. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, and publish the root of `main`.
